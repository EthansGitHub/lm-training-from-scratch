# LM Training on Mac M1

## Setup

- **Tokenizer vocab and training data:** TinyStoriesV2-GPT4-train
- **Validation data:** TinyStoriesV2-GPT4-valid
- **Hardware:** MacBook Air M1, 16 GB memory

## Common hyperparameters

Shared by every run in all three sets:

| Group | Setting | Value |
|---|---|---|
| Model | `vocab_size` | 10000 |
| | `context_length` | 256 |
| | `d_model` | 512 |
| | `num_layers` | 4 |
| | `num_heads` | 16 |
| Optimizer (AdamW) | `beta1` | 0.9 |
| | `warmup_iters` | 100 |
| | `min_lr` | 0.1 × `max_lr` |
| | Cosine annealing cycle | ends at the last training iteration (`cosine_cycle_iters` = `num_train_iters`) |
| | Gradient clipping (max L2 norm) | 1 |
| Training | `batch_size` | 64 |
| Validation | `num_validate_points` | 16 |

A sample script to run experiments on Mac M1 is `experiments/0_TinyStories_Base_Mac_M1/experiment_set0.py`.

## Experiment sets

I have run 3 sets of experiments progressively.

| Set | Goal | Iters | Tokens processed |
|---|---|---|---|
| 0 | Initial sweep over `max_lr`, `weight_decay`, `beta2` | 1000 | 16,384,000 |
| 1 | Finer `max_lr` search | 1000 | 16,384,000 |
| 2 | Longer runs, matching the assignment's MPS budget | 2500 | 40,960,000 |

Tokens processed = iters × `batch_size` × `context_length`.

Training loss, validation loss and gradient norm for all these runs are plotted in [`hyper_tuning.html`](hyper_tuning.html).

### Set 1: finer learning rate

In set 0, the learning rate drove most of the change in validation loss; `beta2` and `weight_decay` mattered much less. So set 1 varies only the learning rate, around the best set 0 run (set0-6, `max_lr` = 0.003). `weight_decay` = 0.1 and `beta2` = 0.95 for all runs.

| Run | `max_lr` | Val loss |
|---|---|---|
| set1-0 | 0.002 | 1.86136 |
| set1-1 | 0.006 | 2.06428 |
| set1-2 | 0.004 | 1.89169 |
| set1-3 | 0.005 | 1.98244 |

### Set 2: longer training

Sets 0 and 1 show that the best `max_lr` is between 0.002 and 0.004, and that validation loss already gets below 2 in 1000 iterations. Set 2 keeps those three learning rates and trains 2.5× longer (2500 iterations), matching the assignment's MPS token budget. `weight_decay` = 0.1 and `beta2` = 0.95 for all runs.

| Run | `max_lr` | Val loss |
|---|---|---|
| set2-0 | 0.002 | 1.63597 |
| set2-1 | 0.003 | **1.60560** |
| set2-2 | 0.004 | 1.66322 |

## Resource usage

- **Peak MPS memory:** 7.54 GiB
- **Wall time:** ~45 min per run for sets 0 and 1, ~2 hr per run for set 3.

## Sample output

Text generated by the best run, set2-1, with these decoding settings:

- **Prompt:** "Once upon a time, there was a"
